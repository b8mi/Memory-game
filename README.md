# Memory Flip

> A tiny matching-card memory game with a move counter and completion timer.

A tiny, standalone Python desktop project. **Only three repository files**: `main.py`, `README.md`, and `requirements.txt`.

## Features

- Sixteen shuffled cards and eight matching pairs
- Flips unmatched cards back after a short delay
- Tracks moves and completion time
- One-click shuffle and restart

## Requirements

- Python **3.10+**
- Tkinter (usually included with Python on Windows)

No third-party packages required. Tkinter ships with most Python installations (including Windows Python).

## Run

```bash
python main.py
```

On Windows, `py main.py` also works when the Python launcher is installed.

## How to use

Click two cards to flip them. Matching pairs stay visible. Find all eight pairs.
